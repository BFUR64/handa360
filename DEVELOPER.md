# Developer Guide to Run in Vite

## Development

```console
npm run dev
```

## Production

```console
npm run build
npm run preview
```

## FAQ

All code now lives under `src`

Use `public` for assets, and pretend it doesn't exist when referencing it, e.g. instead of: `/public/handa360-logo.png` it's `/handa360-logo.png`
